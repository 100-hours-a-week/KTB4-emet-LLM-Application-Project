# A. 재료 변경 판단 (1~10번) 테스트 결과

**테스트 일시: 2026-08-07 08:30경 (커밋 09:32)**

**테스트 방식**: 전체 그래프가 아니라 `nodes/ingredients.py`의 `extract_ingredient`/`extract_ingredient_update`/`apply_ingredient_modification`을 직접 호출. 실제 LLM 호출 발생(케이스당 1회). "이전 재료 목록"이 필요한 케이스는 LLM으로 만들지 않고 Python으로 직접 구성해서 정확히 통제.

**요약**: 10개 중 9개 완전 일치, 1개(7번)는 결과가 안전하지만(중복 없음) 표기 라벨이 문서 기대와 다름. 치명적 문제 없음.

- 판정: ✅ 일치
- 참고: 원본 문서는 "LLM 호출 없이 바로 처리"라고 돼 있었으나 **오기**. 재료 추출은 항상 LLM이 필요함 (문서 수정 권장).

- mode=**diff**, add=[달걀], remove=[계란]
- 최종 목록: `['대파', '돼지고기', '달걀']`
- 판정: ⚠️ 부분 일치 — 중복 없이 처리됐고 개수도 정확(3개 유지)하지만, 문서가 기대한 "사실상 변화 없음"과 달리 표기가 "계란"→"달걀"로 바뀜. `apply_ingredient_modification`이 remove는 정규화 대표명으로 비교하지만 add는 그대로 붙이기 때문. 기능적 문제는 아니고 표시 라벨 취향 차이.
