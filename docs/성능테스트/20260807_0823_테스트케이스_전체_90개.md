> `GOOD_THRESHOLD_SMALL=80%`(N<10) / `GOOD_THRESHOLD_LARGE=70%`(N≥10) (문서 초안의 `60%/80%`는 오기).
> 전부 `evaluate_rag_recipe`/`evaluate_rag_options` 순수 함수 호출로 검증 가능, LLM 불필요.
