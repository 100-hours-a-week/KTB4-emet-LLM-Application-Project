# 🍳 레시피 챗봇 사용 설명서

집에 있는 재료로 뭘 해먹을지 고민될 때, 또는 특정 요리의 레시피가 궁금할 때 채팅으로 물어보면 답해주는 서비스입니다.

## 시작하기

웹 브라우저로 서비스 주소에 접속하면 채팅창이 나옵니다. 하단 입력창에 원하는 걸 자유롭게 문장으로 입력하고 Enter를 누르면 됩니다. 별도의 로그인이나 회원가입은 필요 없습니다.

---

## 기능 1. 가진 재료로 레시피 추천받기

집에 있는 재료를 나열하면, 그 재료로 만들 수 있는 요리를 최대 4개까지 추천해줍니다.

### 사용 예시

**입력**: `계란, 대파, 돼지고기 있어`

**응답**:
```
📋 현재 재료: 계란, 대파, 돼지고기

다음 중 어떤 요리로 하시겠어요?

1. 대파 계란말이 (추가 재료 필요: 소금)
2. 돼지고기 계란볶음 (추가 재료 필요: 간장, 식용유)
3. 돼지고기 대파 볶음 (추가 재료 필요: 간장, 마늘)
4. 돼지고기 계란 덮밥 (추가 재료 필요: 밥, 간장, 양파)
```

집에 이미 있는 재료만으로 만들 수 있는 요리는 "추가 재료 없음"으로 표시되고, 목록 맨 앞쪽에 우선 노출됩니다.

### 마음에 드는 게 없을 때 — 다른 요리 보기

제시된 4개 중에 끌리는 게 없으면 `다른 거 없어?`, `다른 거 보여줘`, `그거 말고 다른 요리는?`처럼 말하면 됩니다. 재료는 그대로 유지한 채, 방금 봤던 요리들과 겹치지 않는 새로운 4개를 다시 계산해서 보여드립니다.

**예시**: "돼지고기, 김치, 두부 있어" → 두부김치/돼지고기김치볶음/김치찌개/김치두부조림 → `다른 거 없어?` → 두부김치찌개/돼지고기두부볶음/김치두부전/돼지고기김치두루치기 (전부 새로운 요리)

### 재료를 추가/제거/변경하고 싶을 때

대화 중간에 재료 상황이 바뀌면 자연스럽게 말하면 됩니다. 처음부터 다시 나열할 필요 없습니다.

| 하고 싶은 것 | 입력 예시 |
|---|---|
| 재료 추가 | `우유도 있어` |
| 재료 제거 | `계란 빼줘` |
| 특정 재료만 남기고 교체 | `사실 김치랑 참치만 있어` |
| 여러 개 동시 변경 | `계란 빼고 우유 추가하고 대파도 넣어줘` |

재료를 바꿀 때마다 그 재료 기준으로 추천 목록이 다시 계산됩니다.

### 궁합이 안 좋은 재료 조합 안내

일부 재료 조합은 전통적으로 궁합이 안 좋다고 알려져 있는데, 이런 조합이 감지되면 추천 목록 아래에 참고 안내가 함께 표시됩니다.

```
💡 참고로 아래 재료 조합은 궁합이 안 좋다고 알려져 있어요:
- 당근+오이: 당근의 아스코르비나아제 효소가 비타민B 복합체와 비타민C를 파괴한다고 알려짐 (전통속설)
```

### 재료가 너무 부실하거나 조합이 이상할 때

재료가 1~2개뿐이거나 서로 어울리지 않는 조합이면, 요리를 만들 수 없다는 안내와 함께 이유를 알려줍니다.

```
📋 현재 재료: 감, 게

죄송해요, 이 재료로는 요리를 만들기 어려울 것 같아요.
이유: 재료 수가 너무 적고, 단감과 게의 조합은 요리로서 어울리지 않아 하나의 완성된
요리로 성립하기 어렵습니다.
```

## 기능 2. 요리 이름으로 바로 검색하기

재료 나열 없이 "이 요리 레시피 알려줘" 하고 특정 요리 이름을 바로 말해도 됩니다.

### 사용 예시

**입력**: `된장찌개 레시피 알려줘`

같은 요리라도 저희 데이터베이스에 여러 버전(집집마다 다른 레시피)이 있으면, 전부 후보로 보여드립니다.

```
요청하신 요리를 찾았어요. 이걸로 만들어드릴까요?

1. 된장찌개 (재료: 집된장, 감자, 애호박, 양파, 청양고추, 느타리버섯, 두부, 다진마늘, 멸치육수)
2. 된장찌개 (재료: 멸치육수, 감자, 양파, 표고버섯, 청양 고추, 대파, 두부, 된장, 고춧가루)
3. 된장찌개 (재료: 두부, 감자, 양파, 청양고추, 애호박, 대파, 멸치가루, 된장, 다진마늘, 고춧가루)
4. 된장찌개 (재료: 쌀뜨물, 애호박, 두부, 양파, 표고버섯, 청양고추, 대파 흰부분, 된장, 다진마늘, 고춧가루)
```

### 저희 데이터베이스에 없는 요리라면?

최근 유행하는 요리이거나 잘 알려지지 않은 요리라서 데이터베이스에 없을 수도 있습니다. 이 경우 실시간으로 웹 검색을 해서 **실제로 존재하는 요리인지 먼저 확인한 뒤** 레시피를 만들어드립니다.

**입력**: `두바이 초콜릿 레시피 알려줘`

```
요청하신 요리를 찾았어요. 이걸로 만들어드릴까요?

1. 두바이 초콜릿 (재료: 카다이프(잘게 부순 것), 버터, 피스타치오 크림(피스타치오 스프레드), 타히니, 다크초콜릿, 피스타치오 분태)
```

만약 요청하신 이름이 실제로는 존재하지 않는 요리(오타, 지어낸 이름, 브랜드명 등)로 확인되면, 아무 레시피나 지어내지 않고 그 사실을 알려드립니다.

```
죄송해요, 요청하신 요리는 실존하는 요리가 아닌 것 같아요.
이유: 검색 결과의 '스크린골프 도시락'은 충청남도 서산시에 위치한 스크린골프장의
상호명이지, 실제 먹을 수 있는 요리나 음식이 아닙니다.
```

## 기능 3. 마음에 드는 요리 선택하고 완성 레시피 받기

목록에서 번호나 요리 이름으로 고르면, 재료 양과 조리 순서까지 포함된 완전한 레시피를 받을 수 있습니다.

### 사용 예시

**입력**: `1번`

```
[돼지고기 계란볶음] (2인분 / 15분)

재료: 돼지고기 200.0g, 계란 3.0개, 대파 1.0대, 간장 2.0큰술

1. 돼지고기는 먹기 좋은 크기로 썰고, 대파는 어슷하게 썰어 준비합니다.
2. 계란은 볼에 풀어 곱게 풀어둡니다.
3. 달군 팬에 기름을 두르고 돼지고기를 넣어 노릇하게 볶습니다.
4. 돼지고기가 익으면 간장 2큰술을 넣어 고루 볶습니다.
5. 풀어둔 계란을 붓고 부드럽게 스크램블하듯 볶습니다.
6. 마지막에 대파를 넣고 살짝 볶은 뒤 불을 끄고 그릇에 담아 완성합니다.
```

### 다양한 선택 표현이 가능합니다

- 번호로 선택: `1번`, `3번이요`
- 요리 이름으로 선택: `계란볶음으로 할게요`
- 정정 표현: `2번 말고 3번으로 할게`

여러 개를 동시에 고르거나(`1번이랑 2번 둘 다 궁금해`) 목록에 없는 걸 말하면, 다시 번호나 이름으로 말해달라고 안내해드립니다.

### 출처가 있는 레시피

저희가 직접 검증한 원본 레시피를 안내해드리는 경우, 답변 마지막에 출처가 함께 표시됩니다.

```
출처: 만개의레시피 (https://www.10000recipe.com/recipe/6937615)
```

---

## 이런 요청은 아직 지원하지 않아요

- 요리와 관련 없는 질문 (예: 날씨, 일반 상식 등)
- 재료나 요리 이름 없이 막연한 요청 (예: "레시피 추천해줘"만 입력)
- 식단 구성, 영양 상담 등 레시피 추천/검색 외의 기능

이런 경우 죄송하다는 안내와 함께 왜 처리할 수 없는지 이유를 알려드립니다.

---

## 알아두면 좋은 점

- **대화 흐름 유지**: 재료를 바꾸거나 다시 물어봐도 이전 대화 맥락을 기억합니다. 새 대화를 시작하고 싶으면 화면의 "새 대화" 버튼을 누르면 됩니다.
- **일정 시간 뒤 자동 초기화**: 오랫동안(수 시간) 사용하지 않으면 대화 기록이 자동으로 정리됩니다.
- **같은 레시피 재선택**: 한 번 확정했던 레시피를 다시 선택하면 즉시 같은 내용을 다시 보여드립니다.
